# Architecture Plan

The previous multi-agent platform proposal was retired on 2026-07-08 because
it no longer represented the product direction.

DevSynapse is transitioning from a generic local coding agent to a packaged
conversational desktop copilot for GitHub, GitHub Actions and repository work.
The active planning documents are:

- [Product vision](product-vision.md)
- [Product contract](product-contract.md)
- [Repository operations architecture](architecture/repository-operations.md)
- [Repository operations roadmap](roadmap.md)
- [ADR 0001: Repository operations copilot](decisions/0001-repository-operations-copilot.md)
- [ADR 0002: Packaged desktop and GitHub first](decisions/0002-packaged-desktop-github-first.md)

The roadmap distinguishes shipped v1 behavior from target behavior. Do not
implement components from the retired proposal unless they are reintroduced
through an accepted decision and an active roadmap phase.
