# Release v0.6.3

## Summary

`v0.6.3` is a patch release for chat project workflow polish, frontend
maintainability and UI smoke coverage.

## Highlights

### Chat Project Workflow

- The chat project manager now supports a more complete project workflow from
  the chat workspace: search, active/missing filters, creation, selection,
  refresh and admin removal.
- Creating or selecting a project from chat preserves the selected project when
  a fresh conversation is opened for that project.
- The existing fast "Aprovar tudo" operator flow is unchanged.

### Frontend Maintainability

- Conversation rail rendering is isolated in a dedicated React component.
- Project manager rendering and local form/filter state are isolated in a
  dedicated React component.
- Chat message Markdown rendering now handles in-progress fenced code blocks
  and exposes a copy action for code blocks.
- Unused project-manager CSS selectors were removed and status-filter naming
  was clarified.

### UI Validation

- The Playwright UI smoke test now opens the project manager, creates a project
  through the chat UI and validates that the new project remains selected.

## Platform Support

The supported desktop downloads remain:

- Linux x86_64 `.deb`
- Linux x86_64 `.rpm`
- Windows x86_64 Tauri installer

The supported shell installer/update path remains Debian/Ubuntu-style Linux.
macOS packaging remains configured but unvalidated.

## Release Compliance

- Application version: `0.6.3`
- Release tag: `v0.6.3`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: none
- API contract impact: none

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.6.3
```

No database migration or manual runtime configuration step is required for this
release.
