# Release v0.7.0

## Summary

`v0.7.0` is a feature release for reproducible agent evaluation, public product
evidence and chat command-completion stability.

## Highlights

### Reproducible Agent Evaluation

- Added a disposable evaluation harness that can exercise DevSynapse against
  small project fixtures without touching user repositories.
- Added `make eval-agent` and `scripts/eval_agent.py` so maintainers can
  regenerate local appraisal artifacts.
- Documented no-LLM benchmark scenarios and real-LLM evidence under
  `docs/evaluation`.

### Public Evidence

- Added structured JSON results, appraisal notes and screenshots from the
  `2026-05-02` evaluation pass.
- Added real DeepSeek evidence showing the agent inspecting a disposable Python
  project, diagnosing failing tests, editing the bug and finishing with
  `3 passed in 0.01s`.
- Refreshed the README, product showcase and documentation index around the new
  evidence set.

### Command Completion Stability

- Expanded API models, frontend types and client helpers for structured
  settings, monitoring and command-completion payloads.
- Stabilized chat command completion behavior in the brain/orchestration path.
- Added backend and UI smoke coverage for project-scoped chat command
  completion.

## Platform Support

The supported desktop downloads remain:

- Linux x86_64 `.deb`
- Linux x86_64 `.rpm`
- Windows x86_64 Tauri installer

The supported shell installer/update path remains Debian/Ubuntu-style Linux.
macOS packaging remains configured but unvalidated.

## Release Compliance

- Application version: `0.7.0`
- Release tag: `v0.7.0`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: none
- API contract impact: expanded typed response models for existing routes

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.7.0
```

No database migration or manual runtime configuration step is required for this
release.
