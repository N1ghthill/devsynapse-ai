# Release v0.8.0

## Summary

`v0.8.0` is a reliability release for persistent agent task recovery, generated
project continuity and refreshed DevSynapse brand assets.

## Highlights

### Agent Task Recovery

- Added persistent agent task runs for action-oriented chat work.
- Stored original goals, project scope, command results, policy blocks,
  execution failures, final responses and next actions in SQLite.
- Injected the active agent run into prompt context so later turns can recover
  from missing dependencies, blocked commands or normal command failures.
- Updated auto-execution replay behavior so recoverable failures become context
  for the next step instead of ending the task.

### Project Continuity

- Refreshed long-lived command bridge project lookup from the persisted project
  registry before chat and command execution.
- Registered projects inferred under the configured repositories root after a
  successful command, keeping generated projects discoverable in later turns.
- Included project paths in backend project context so the assistant can work
  with registered directories more reliably.

### Brand Assets

- Replaced the DevSynapse browser and desktop icon set with the new source asset
  under `assets/devsynapse-icon.png`.
- Added `assets/devsynapse-icon-square.png` as the padded square source required
  by Tauri icon generation.
- Regenerated browser favicon and Tauri PNG, ICO, ICNS, Android and iOS icon
  variants from the new source asset.

## Platform Support

The supported desktop downloads remain:

- Linux x86_64 `.deb`
- Linux x86_64 `.rpm`
- Windows x86_64 Tauri installer

The supported shell installer/update path remains Debian/Ubuntu-style Linux.
macOS packaging remains configured but unvalidated.

## Release Compliance

- Application version: `0.8.0`
- Release tag: `v0.8.0`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: migration `11` adds `agent_runs` and
  `agent_run_events`
- API contract impact: no new public routes; chat/execute behavior now records
  task-run context internally

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.8.0
```

The updater applies SQLite migrations automatically. Migration `11` adds local
agent task-run tables; no manual runtime configuration step is required.
