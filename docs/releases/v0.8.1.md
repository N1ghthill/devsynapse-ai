# Release v0.8.1

## Summary

`v0.8.1` is a patch release that republishes the `v0.8.0` reliability work with
aligned desktop package metadata.

## Changes

- Aligned the FastAPI runtime version, frontend package version and Tauri
  package versions to `0.8.1`.
- Fixed Linux desktop release packaging by ensuring Tauri-generated `.deb` and
  `.rpm` artifacts use the same version as the release tag.
- Added release workflow checks that fail early when the release tag version,
  `frontend/package.json`, `frontend/src-tauri/tauri.conf.json` and
  `frontend/src-tauri/Cargo.toml` diverge.

## Platform Support

The supported desktop downloads remain:

- Linux x86_64 `.deb`
- Linux x86_64 `.rpm`
- Windows x86_64 Tauri installer

The supported shell installer/update path remains Debian/Ubuntu-style Linux.
macOS packaging remains configured but unvalidated.

## Release Compliance

- Application version: `0.8.1`
- Release tag: `v0.8.1`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: no new migration after `v0.8.0`
- API contract impact: no new public routes or fields after `v0.8.0`

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.8.1
```

The updater applies SQLite migrations automatically. Systems updating from
versions before `v0.8.0` will receive migration `11`, which adds local agent
task-run tables.

## Verified

Validated on `2026-05-03`:

- full local `make verify`: passed
- backend test suite: `233 passed`
- Python/Ruff checks, shell syntax checks, Python script compilation and
