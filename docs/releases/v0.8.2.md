# Release v0.8.2

## Summary

`v0.8.2` is a patch release for chat UI resilience, streaming stability, agent
recovery context and release download hygiene.

## Changes

- Added a React error boundary so unexpected UI render failures show a recovery
  screen instead of leaving the app blank.
- Added collapsible command output blocks for long chat command results.
- Improved streaming chat scroll behavior and abort handling so stale streams
  are cancelled when the chat view unmounts or a new request starts.
- Added stuck-context awareness after repeated blocked or failed command
  outcomes so the assistant is nudged away from repeating the same action.
- Offloaded synchronous DeepSeek calls from async request handlers to worker
  threads.
- Added stable release asset aliases for landing-page downloads:
  `DevSynapse_AI_latest_x64-setup.exe`, `DevSynapse_AI_latest_amd64.deb` and
  `DevSynapse_AI_latest_x86_64.rpm`.
- Added `make install-ui-smoke` and clearer Playwright browser installation
  guidance for UI smoke failures.

## Fixes

- Fixed a malformed CSS block that broke the frontend production build after UI
  styling changes.
- Kept release workflow validation strict for Linux `.deb`, Linux `.rpm` and
  Windows installer signatures before publishing release assets.

## Platform Support

The supported desktop downloads remain:

- Linux x86_64 `.deb`
- Linux x86_64 `.rpm`
- Windows x86_64 Tauri installer

The supported shell installer/update path remains Debian/Ubuntu-style Linux.
macOS packaging remains configured but unvalidated.

## Release Compliance

- Application version: `0.8.2`
- Release tag: `v0.8.2`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: no new migration after `v0.8.0`
- API contract impact: no new public routes or fields after `v0.8.0`

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.8.2
```

The updater applies SQLite migrations automatically. Systems updating from
versions before `v0.8.0` will receive migration `11`, which adds local agent
task-run tables.
