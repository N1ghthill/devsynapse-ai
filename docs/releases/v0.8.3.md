# Release v0.8.3

## Summary

`v0.8.3` improves chat recovery around privileged setup commands and adds the
first adaptive multi-provider LLM layer for OpenRouter, OpenCode Go and
OpenCode Zen.

## Changes

- Added manual setup classification for `sudo` and interactive privilege
  failures so the chat stops retrying commands that need a human terminal.
- Added prerequisite revalidation through `GET /prerequisites`, including safe
  checks for common project tooling such as Git, Python, Node, npm, Rust, Cargo
  and Tauri CLI.
- Added OpenRouter, OpenCode Go and OpenCode Zen API key settings.
- Added OpenAI-compatible provider routing for prefixed models:
  `openrouter:*`, `opencode-go:*` and `opencode-zen:*`.
- Added model discovery for OpenRouter and OpenCode Go plus seeded direct
  provider catalog entries.
- Added persistent LLM model catalog storage.
- Added per-user and per-model LLM request telemetry for token counts, cache
  hits, time to first token, total latency, error rate and real or estimated
  cost.
- Added adaptive model selection that can prefer cheaper discovered models for
  simple or budget-sensitive tasks while keeping the configured model for
  critical work.
- Added dashboard visibility for model telemetry grouped by user and model.

## Fixes

- Trusted admin shell execution now uses `pipefail` so piped command failures
  are not hidden by a successful final command in the pipeline.
- The chat UI now surfaces blocked setup work as a manual setup state with a
  revalidation path instead of encouraging repeated authorization loops.

## Release Compliance

- Application version: `0.8.3`
- Release tag: `v0.8.3`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: migration `12` adds LLM model catalog and request
  telemetry tables
- API contract impact: new `/prerequisites`, `/settings/llm/models` and
  `/settings/llm/discover` routes; settings now include OpenRouter and OpenCode
  API key fields

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.8.3
```

The updater applies SQLite migrations automatically.
