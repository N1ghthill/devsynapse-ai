# Release v0.8.4

## Summary

`v0.8.4` hardens the development-agent loop and stabilizes the chat layout. The
release focuses on the operator pain points found during local validation: long
assistant output breaking the UI, command cards becoming hard to scan and the
agent returning too early before finishing requested project work.

## Changes

- Added agent completion guard tracking for expected file edits and pytest
  validation during trusted auto-execution.
- Added recovery prompting when the model tries to finish before the tracked
  development checklist is complete.
- Added detection for trailing task markers such as `Agora o README.md:` so the
  agent treats them as pending action instead of a finished response.
- Added a command execution timeline in chat messages to make command progress,
  status, output and failures easier to inspect.
- Expanded the Playwright UI smoke test to cover long chat text, command
  timeline rendering, compact controls and desktop/mobile horizontal overflow.

## Fixes

- Fixed chat message, code block, command card and sidebar wrapping so large
  project output remains inside the visible workspace.
- Fixed several compact buttons and header controls that could wrap labels or
  look broken at narrower widths.
- Moved broad layout and chat styling into dedicated CSS modules for easier
  maintenance.
- Updated local development startup output to describe the configured admin
  password instead of implying a stale default.

## Release Compliance

- Application version: `0.8.4`
- Release tag: `v0.8.4`
- Supported desktop targets: Linux x86_64 and Windows x86_64
- Supported shell installer target: Debian/Ubuntu-style Linux with `apt`
- Runtime state: config, SQLite data and logs remain outside the source checkout
- Database migration impact: none
- API contract impact: no new routes or response fields; agent auto-execution
  behavior is more conservative around incomplete development tasks

## Migration

Update normally:

```bash
devsynapse update
```

or pin this release:

```bash
devsynapse update --version v0.8.4
```

No SQLite migration is required for this release.
